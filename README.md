# CIS25_Fall2025
# Midterm – Module 8: Bank Account Simulation

## Overview
This program simulates a simple BankAccount class that manages a user’s balance and records transactions to a file using C++ file I/O.  
It demonstrates class design, object-oriented programming, and file handling in C++.

---

## Features
- Deposit money into the account  
- Make purchases (deduct from balance)  
- Display the current balance  
- Save each transaction to `transactions.txt`

---

### 1. Compile
Open a terminal or command prompt and run:
